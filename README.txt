ENSIKLOPEDIA MUSIK TRADISIONAL LOMBOK
=====================================

Ini adalah kerangka awal proyek UTS Sistem Multimedia.

STRUKTUR:
- assets/images : simpan gambar alat musik
- assets/audio  : simpan rekaman suara alat musik
- assets/videos : simpan video pertunjukan
- assets/icons  : simpan ikon atau logo
- css/style.css : gaya tampilan website
- js/data.js    : data alat musik
- js/main.js    : interaksi utama website
- js/quiz.js    : fungsi kuis

HALAMAN:
- index.html   : beranda
- katalog.html : katalog alat musik
- detail.html  : detail alat musik
- audio.html   : halaman audio
- galeri.html  : galeri video
- kuis.html    : kuis interaktif
- tentang.html : informasi website

CATATAN:
Struktur ini sengaja dibuat tanpa folder proyek bersarang/duplikat.
Kode akan dimasukkan satu per satu dengan arahan bertahap.
